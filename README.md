# GreenLink

Простой Android-мессенджер для общения по Bluetooth напрямую между двумя телефонами — без интернета, без сервера, без регистрации.

## Возможности
- Поиск и подключение к другому телефону с этим же приложением поблизости.
- Подключение только с согласия второй стороны (всплывающий запрос ✅ / ❌).
- Обмен текстовыми сообщениями в обе стороны после подключения.
- Работает только между Android-телефонами (классический Bluetooth, не BLE).
